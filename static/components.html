Asking questions

Text input

A single line of text: a name, a reference number, a town.

For example, Acacia Avenue
HTML — copy this into a Track A page 
<div class="govuk-form-group">
  <h1 class="govuk-label-wrapper">
    <label class="govuk-label govuk-label--l" for="road-name">
      What is the name of the road?
    </label>
  </h1>

  <div id="road-name-hint" class="govuk-hint">
    For example, Acacia Avenue
  </div>

  <input class="govuk-input" id="road-name" name="roadName" type="text" aria-describedby="road-name-hint">

</div>
Nunjucks — copy this into a Track B template 
{% from "govuk/components/input/macro.njk" import govukInput %}
{{ govukInput({
  label: { text: "What is the name of the road?", classes: "govuk-label--l", isPageHeading: true },
  hint: { text: "For example, Acacia Avenue" },
  id: "road-name",
  name: "roadName"
}) }}

Radios with a conditional reveal

Ask a follow-up question only when it is relevant. Needs JavaScript to hide and show.

Needs JavaScript

Was anyone injured?

HTML — copy this into a Track A page 
<div class="govuk-form-group">

  <fieldset class="govuk-fieldset">

  <legend class="govuk-fieldset__legend govuk-fieldset__legend--l">

    <h1 class="govuk-fieldset__heading">
      Was anyone injured?
    </h1>

  </legend>

  <div class="govuk-radios" data-module="govuk-radios">

    <div class="govuk-radios__item">
      <input class="govuk-radios__input" id="injured" name="injured" type="radio" value="yes" data-aria-controls="conditional-injured">
      <label class="govuk-label govuk-radios__label" for="injured">
        Yes
      </label>

    </div>

    <div class="govuk-radios__conditional govuk-radios__conditional--hidden" id="conditional-injured">
      <div class="govuk-form-group"><label class="govuk-label" for="injury-details">How many people?</label><input class="govuk-input govuk-input--width-3" id="injury-details" name="injuryDetails" type="text"></div>
    </div>

    <div class="govuk-radios__item">
      <input class="govuk-radios__input" id="injured-2" name="injured" type="radio" value="no">
      <label class="govuk-label govuk-radios__label" for="injured-2">
        No
      </label>

    </div>

  </div>

</fieldset>

</div>
Nunjucks — copy this into a Track B template 
{% from "govuk/components/radios/macro.njk" import govukRadios %}
{{ govukRadios({
  name: "injured",
  fieldset: {
    legend: { text: "Was anyone injured?", classes: "govuk-fieldset__legend--l", isPageHeading: true }
  },
  items: [
    {
      value: "yes",
      text: "Yes",
      conditional: {
        html: '<div class="govuk-form-group"><label class="govuk-label" for="injury-details">How many people?</label><input class="govuk-input govuk-input--width-3" id="injury-details" name="injuryDetails" type="text"></div>'
      }
    },
    { value: "no", text: "No" }
  ]
}) }}

  • Select how big the pothole is

<div class="govuk-error-summary" data-module="govuk-error-summary">
  <div role="alert">
    <h2 class="govuk-error-summary__title">
      There is a problem
    </h2>
    <div class="govuk-error-summary__body">

        <ul class="govuk-list govuk-error-summary__list">

          <li>

            <a href="#road-name">Enter the name of the road</a>

          </li>

          <li>

            <a href="#size">Select how big the pothole is</a>

          </li>

        </ul>

    </div>
  </div>
</div>
Nunjucks — copy this into a Track B template 
{% from "govuk/components/error-summary/macro.njk" import govukErrorSummary %}
{{ govukErrorSummary({

  errorList: [
    { text: "Enter the name of the road", href: "#road-name" },
    { text: "Select how big the pothole is", href: "#size" }
  ]
}) }}
